## "Precise" now slows down the whole scroll, not just its first tick

If you had **Precise (slower for small movements)** turned on, you were getting almost nothing for
it. Every tick of the wheel but the very first came out exactly the same with the setting on or
off, so the toggle read as doing nothing at all — because at the speed a hand actually turns a
wheel, it very nearly was.

The setting works on the curve that turns how fast you are scrolling into how far the page moves.
That curve has a floor, for the slowest scroll, and a ceiling, for the fastest. "Precise" only ever
lowered the floor — and a wheel reaches the ceiling within a tick or two of starting. Measured
against the running engine, a scroll at a normal pace travelled 8% less with the setting on.

It now pulls the ceiling down with the floor, so it applies for as long as you keep scrolling: a
little under half the distance, throughout. It stays clearly milder than holding the **Precise
scroll** modifier key, which is still there for when you want the finest control the engine can
give.

## App profiles for apps that live on another Mac

With iCloud sync on, every Mac gets every other Mac's app profiles — including ones for apps that
are not installed on the Mac you are looking at. The window never said so. The profile showed a
blank sheet of paper where the app's icon should be, which reads like a broken icon rather than
like an app that simply isn't here.

Those profiles now show a dashed placeholder instead, and the line under the app's name says
"not installed on this computer". The settings still work and still sync — the note is about this
Mac, not about the profile.

## The Accessibility button asks once

Pressing **Open Device Control and Data Access…** used to put two things on screen at once: the
System Settings pane, and macOS's own permission dialog on top of it, whose only other choice was
Deny. One button, apparently asking the same question twice. It now opens the pane and nothing
else. Leios is already listed there waiting for its switch, so the dialog was never what put it in
the list.

While in there: macOS 27 renamed that pane from Privacy & Security → Accessibility to Privacy &
Security → Device Control and Data Access, and Leios was still sending you to the old name. It
calls it what your Mac calls it now.

## Nothing to redo

Your settings, per-app profiles, button mappings and Accessibility permission all carry across an
update. Leios can install this one itself if you are on beta 10 with **Include pre-release
versions** turned on.
