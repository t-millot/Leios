## Leios no longer goes quietly dead after you install over it

If you have installed one beta over another — dragged a new copy into Applications, or gone back
to an older one — there is a good chance Leios has been doing nothing at all since, without ever
saying so. This release fixes that, and it is worth reading if scrolling has felt untouched
lately.

The engine does not run inside the settings window; it runs as a small background helper that
lives inside the app bundle and is started by macOS. Replacing the app replaces that helper too,
while macOS is still holding a registration that points at the copy that used to be there. It
refuses to start the new one — it is killed on sight, as a signing violation — and it keeps being
killed every time it is asked to start.

Leios was supposed to notice and repair exactly this. It could not: the repair worked by asking
the helper which version it was, so it only ever ran for a helper that was alive enough to answer.
When the helper was being killed outright there was nothing to ask, and nothing re-registered it.

Now the app repairs it: if the helper has been registered but silent for a few seconds, Leios
re-registers it once, which is what makes macOS let go of the stale registration and start the
helper that is actually there.

## And it says so when something is wrong

The only sign of any of this used to be a line of small grey text in the sidebar reading "Helper
is enabled but not responding yet…", which reads like something still starting up rather than
something that has failed for good.

A helper that stays silent now raises a proper notice at the top of the window, in red, saying
that nothing is being remapped and why that usually happens — with a **Restart the Helper** button
next to it, so the repair is also something you can ask for directly.

## Nothing to redo

Your settings, per-app profiles, button mappings and Accessibility permission all carry across an
update. Leios can install this one itself if you are on beta 8 with **Include pre-release
versions** turned on.

If Leios is currently stuck, install this build over it and open the window once — it will sort
itself out within a few seconds of launching.
